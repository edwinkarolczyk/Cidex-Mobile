Warsztat Menager Mobile (WMM) — aplikacja mobilna współpracująca z Warsztat Menager przez lokalne WM API.

Aktualny zakres obejmuje logowanie użytkownika WM, Planistę, Maszyny, Narzędzia, Dyspozycje, Magazyn, skanowanie QR oraz zdjęcia.

Na Windows przygotowane są skrypty `scripts/setup_windows.bat` i `scripts/run_emulator.bat` do uruchamiania aplikacji w emulatorze Androida.

Bieżące zmiany rozwojowe są zapisywane w `docs/WMM_CHANGES.md`.
